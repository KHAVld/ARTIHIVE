# Changelog

## 2.0.0

- Added POLY mode on the second HOME tab with all 27 keys arranged chromatically.
- Added eight-voice oldest-note allocation, octave selection, global ROOT, SHARP, DETUNE and MOD controls.
- Added context-sensitive envelope editing for all voices or the newest held POLY voice.
- Preserved the eight independently tuned envelope-trigger voices and latches in DRONE mode.
- Added exact 10–400 BPM arpeggiation and user-pattern controls on the physical ARP button.
- Added global mutation and undo behavior on the physical SEQ button.
- Added output compression, revised interface geometry, final page titles, theme outlines and native 240 x 240 presentation.
- Added application and loader support for UC25HQ80 flash JEDEC `0xB36014` while retaining Puya P25Q80 `0x856014` support.
- Added Firmware Hub metadata and a square repository card image.

## 1.9.0

- Stabilized the eight-voice DRONE instrument, presets, Hyper LFO, stereo delay modulation, output chain and update-loader workflow.
- Added UI themes, migration support, safety checks, deterministic release packaging and host regression coverage.
