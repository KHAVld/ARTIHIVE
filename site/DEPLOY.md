# ARTIHIVE 2.0.5 website deployment

This directory is ready to be published as the root of a GitHub Pages site.

## GitHub Pages

1. Copy every file and directory from this package to the publishing branch root.
2. In **Settings → Pages**, select **Deploy from a branch**.
3. Select that branch and the root (`/`) directory.

The `.nojekyll` marker is included. The site is static and requires no build step.

The browser emulator loads `assets/downloads/artihive-2.0.5.fwsc` from the published site. Keep that path unchanged.
